# Entregas de Ciência de Dados

Este repositório está organizado por trabalho:

```text
trabalho_1_preprocessamento/   Trabalho 1 — Pré-processamento
trabalho_2_classificacao/     Trabalho 2 — Classificação
trabalho_3_clusterizacao/     Trabalho 3 — Clusterização (em desenvolvimento)
```

Os arquivos `p1.py` e `p2.py` pertencem ao Trabalho 3 e estão em
`trabalho_3_clusterizacao/scripts/`. Cópias imutáveis e idênticas foram
preservadas em `trabalho_3_clusterizacao/scripts/originais/`.

Cada entrega possui documentação e dependências próprias. Consulte o README do
diretório correspondente antes de executar seus scripts.
